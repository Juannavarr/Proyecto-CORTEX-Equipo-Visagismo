# Fase 2 — Semana 5: Flujo perceptivo

La actividad pide describir el recorrido del dato desde su entrada hasta que el agente lo interpreta como útil, y diseñar una regla simple para distinguir una pregunta de una afirmación.

## Recorrido resumido

1. Recibir el texto, la imagen o la descripción proporcionada por el cliente.
2. Identificar qué datos relevantes están presentes y cuáles faltan.
3. Interpretar la solicitud y confirmar el objetivo si no está claro.
4. Recoger preferencias y límites de estilo y mantenimiento.
5. Filtrar opciones compatibles con la información disponible.
6. Explicar una recomendación y alternativas; ajustar si el cliente indica que no le convence.

## Pendiente de completar para la entrega de Semana 5

La guía pide una regla explícita para diferenciar una **pregunta** de una **afirmación**. Esa regla no está descrita con claridad en el material revisado. Debe acordarse con el equipo; no se inventa aquí.
